# snapcheck-website
This website provides users with information and images about vintage snapback hats to assist them in authenticating and learning about their own collection.

## Live Demo
https://snapcheck.wiki/

## Description
This website was created because there is currently no place online that documents tags, styles, and brands of vintage snapbacks. It was built to consilidate information about vintage snapbacks that are no longer produced. It is meant for collectors and individuals who may have inherited or found a hat they want to know more about.

## Built with
- HTML5
- CSS3

### Getting Started
No special tools needed, just a web browser

### Installation
1. Clone or download this repository
2. Open snapcheck.wiki in your browser
